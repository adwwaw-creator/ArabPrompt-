# DawAi — منصة موحدة

## الملفات
- `index.html`: واجهة DawAi الرئيسية بأيقونتين.
- `library.html`: مكتبة 110 برومتات + مولّد الأوامر ولوحة الإدارة المحلية.

## التشغيل والنشر
افتح `index.html` محلياً أو ارفع الملفات الأربعة إلى جذر مستودع GitHub ثم فعّل Settings → Pages → Deploy from a branch → main / root.

## Google AI Studio
يمكن استخدام الملفات كمرجع لإعادة بناء الواجهة في Build؛ لا يلزم API لعمل الموقع الثابت.

**مهم:** رابط ArabiPrompt يفتح الموقع الأصلي، ولا يتجاوز الاشتراك أو الدفع. التعديلات في المكتبة محلية.
